Local UI preview

Edit the actual popup and HUD locally.

Run this page through a local server, refresh it, and the real bookmarklet UI will render from the source files in src/.

How this works
The page loads the same source scripts the bookmarklet uses, so you can tweak the HTML, CSS, and layout in src/ and see the popup update on refresh.

Edit locally

Change src/styles.js, src/primer.js, and src/clock-hud.js, then reload this page.

Bookmarklet build

Keep publishing dist/park-pass.js for the live bookmarklet. This preview does not replace the hosted bundle.

Local workflow

python -m http.server 8000
open http://localhost:8000/index.html
edit src/*.js
refresh browser
