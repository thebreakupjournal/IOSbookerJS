Runbook

How to use it

1
Open BC Parks

Navigate to the reservation page where the form and Next button live.

2
Prime booking

Open the modal, choose booking date, park, pass, and visit time, then click Prime only or Prime / arm.

3
Set the release time

Use the Schedule tab to choose release time in HH:MM:SS and set lead seconds.

4
Run timing tests

Use Test to measure Next-click to #firstName hydration. Results appear in the Timings tab.

Controls

What each button does

  • Test - primes the page, clicks Next, and stores a timing sample.
  • Prime only - fills Page 1 and minimizes the HUD.
  • Prime / arm - fills Page 1, then schedules the Next click.
Timing

What the Timings tab shows

  • Average, median, fastest, and slowest run time.
  • A chronological list of each test run.
  • Copy and clear actions for managing stored samples.
