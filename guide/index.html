3
Open BC Parks

Start from the reservation page

Go to the BC Parks reservation page, then run the bookmarklet. The UI will open with the clock, booking controls, and the new timing tab.

Keep Safari visible and prevent the phone from locking while you work.
4
Prime

Set release time and prime the booking

  1. Open the Prime Booking modal.
  2. Set the booking date, park, pass, and visit time.
  3. Open the Schedule tab.
  4. Set release time in HH:MM:SS.
  5. Set lead seconds.
  6. Choose Prime only or Prime / arm.
Prime only

Fill Page 1 and stop there.

Prime / arm

Fill Page 1 and schedule the Next click.

5
Test

Run timing tests and review results

Use Test to measure the time between clicking Next and the first booking field appearing. Results show up in the Timings tab.

  • Test saves each run locally.
  • Timings shows average, median, fastest, and slowest.
  • Use Copy results if you want to share or compare runs.
Buttons

What to press

  • Test - primes and records a run.
  • Prime only - fills Page 1.
  • Prime / arm - fills Page 1 and schedules Next.
Timing tab

What you’ll see

  • Average, median, fastest, slowest.
  • A run-by-run list.
  • Copy and clear actions.
